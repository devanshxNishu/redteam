# Saved context manifests before ownership

Version0.45 adds internal exclusive publication and pre-task verification in `src/context-analyst-artifacts.ts`. It saves the exact checked context plan and generation bytes before a future coordinator acquires ownership. It creates no task, ledger, provider request, credential read, result or audit. Saved manifest labels remain the original preparation-time labels; the separate verified envelope records publication checks. Task-bound historical retrieval and runtime integration remain next. There is no new CLI/API route.

`saveContextAnalystManifest(store, preparation)` requires the actual current in-process preparation from that exact Store, not a copy, serialized flag or reconstructed manifest. It fully checks current declaration, source files, exact generation and frozen plan semantics before creating owner-only `.redteam/context-analyst-runs/RUN_UUID`. It publishes compact canonical `manifest.json` and `generation.json` exclusively, verifies private single-link bytes, and performs complete current validation again. An existing directory or concurrent losing writer fails; no file is replaced, completed by retry, or adopted. Partial or uncertain publication preserves factual orphan bytes without permission or ownership.

`verifySavedContextAnalystManifest(store, preparation)` is a pre-ownership check with the same current preparation requirement. It checks exact pinned hashes and complete file bytes, reconstructs current canonical semantics, re-reads both files and applies final current metadata/deadline guards. It returns immutable checked data with `executionAuthority: not_granted` and `ownership: not_acquired`. A separate in-process receipt is registered only after save succeeds. Verification requires that successful receipt and original preparation, so even complete files left by a failed save cannot be adopted. Restarted processes have no such receipt; task-bound historical reading remains future work. A run UUID alone cannot read/adopt a publication. Revocation, source correction/withdrawal, expiry, elapsed inference deadline, unsafe/missing/changed files or scope mismatch deny delivery.

`checkContextAnalystManifestBytes` in the configuration module copies bounded buffers before awaits, parses strict UTF-8 JSON, normalizes configuration, checks current declaration/source/packet/generation and reconstructs the exact original run/task IDs and preparation/deadlines. Every canonical manifest/generation byte must match the rebuilt plan. It accepts no extra authority fields, changed semantics or alternate formatting. Future preparation times, equal run/task IDs and path-like identities fail. It can validate a historical inference window while current source/declaration rights still permit access. It never registers a preparation capability, saves data, adopts an orphan, slides a deadline or grants execution.

Manifest bytes are bounded to24,000 and generation to500,000; original pretty preparation/generation bounds also remain. Empty and large valid packets keep all selected sources. Source text and references remain untrusted data. Canonical hashes authenticate local consistency only. Private canonical parents, no-follow/single-link file checks and exclusive publication apply; local operator/runtime/clock/DB/filesystem, delivered copies/backups and changes after the final observed read remain boundaries. No atomic transaction across files or independent content-rights/semantic attestation is claimed.

Next: task-bound historical saved-reader with exact task/manifest/workspace binding, then context-specific fenced task/accounting/transport and result publication/recovery. Check saved bytes before ownership and full current files/rights before each send/response/seal/publication/delivery. Preserve separate count liability and frozen deadlines. V1 `analyst-runs` artifacts and their parser remain unchanged; do not cast new context manifests into them. Live compatibility, semantic review, wider news/report/web, human usefulness/behavior validation, paid demand and production isolation remain open.
