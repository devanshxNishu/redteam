# Checked evidence-link export plan

Next narrow slice after 0.23.0: allow an explicitly selected controlled outcome evidence link as a fifth report-export record kind. The existing release still exports only review/action/experiment/comparison records. This plan enables nothing until implementation and verification pass.

Reuse the checked private outcome reader, full historical action-event/source/plan/comparison/browser lineage, and final synchronous publication/source guard. Export only the existing public outcome projection, preserving supplied note, exact IDs/report hashes, fixed unadjudicated assessment, local chronology, factual comparison verdict, and limitations. Omit private paths, access targets/grants, catalog fingerprints, private action-history pins, artifact paths/bytes, code, actor/research data, sessions and credentials. Supplied text may contain private information; there is no universal detector. Source artifact metadata is not a download permission.

Extend strict typed selection and duplicate checks under a versioned export contract. Preserve compatibility with saved existing four-kind exports; do not rewrite prior files or source plans/actions. Keep current total-record/browser-evidence/serialized-size limits explicit. A linked outcome can transitively depend on two reviews and a historical action/plan/comparison; count and bound those dependencies rather than bypass existing read/size budgets through repeated links. Do not infer prospective human validity, hypothesis success, intervention execution, sample adequacy, independence, causality or commercial behavior from inclusion in a bundle.

Private export pins must bind the exact link publication and all currently checked source identities/history/bytes. Creation and retrieval must deny changed link artifacts, source reports, old action notes, source catalogs, job availability or time state. Later legitimate action revisions should keep a historical link/export readable. Recheck permissions and current source availability around publication and inside catalog guards; bind final API/download delivery to the selected checked records. Preserve uncertain publication, delivered-copy, orphan, no-retry and no-automatic-cleanup limits.

Verify terminal, protected API and eventual dashboard selection without silently broadening source scope. The dashboard must resolve a link through exact known plan/comparison/completed review parents, clear stale/restricted detail and selection, preserve its title/typed IDs, and never add a link to a bundle automatically. Its report body and Markdown must remain literal; actual JSON/Markdown downloads must match checked saved bytes. No new artifact download is added.

Meaningful tests include old-export compatibility, a genuine freeze-before-capture linked record in a mixed bundle, fixed labels and unchanged sources, strict duplicate/unknown/getter inputs, distinct and repeated transitive dependencies/limits, changed own/source/history/availability/clock state, guarded insertion and final response races, unsafe bytes/paths, exact literal render/download bytes, later legitimate action updates, normal-poll client clearing, late responses, desktop/mobile layout, installed archive checks and a normal verified GitHub push. Independent U06 human outcome adjudication and research/commercial/isolation/hierarchy gates remain open.
