THE SAME WORKSPACE, FROM YOUR SHELL

Made for the terminal.

Install Redteam. Grant access. Run a review.
Open the evidence wherever you work.

Install a packaged build

NODE 24.12+
npm install --global ./redteam-0.17.0.tgz
redteam --help
redteam ui

The release archive is generated locally with npm pack. Registry publication is not required.

Grant project access

redteam access grant \
  --path ./my-app \
  --allow code:read,code:test

redteam access list
redteam access revoke GRANT_ID

Run and inspect

redteam review --demo broken
redteam review --demo fixed
redteam runs list
redteam actors demo
redteam actors list
redteam verify RUN_DIRECTORY

Start from source

npm install
npm run build
npm link
redteam ui

Review data and credentials stay under the current project's .redteam/ directory.
